 - [ ] Можно отдельно сохранить/экспортировать в wav выделенный луп.

Стек: Rust + Dioxus


Шаг 2: Момент релиза (Когда накопились фичи)Вы понимаете, что плеер готов к новой версии (например, v0.1.0-alpha.2). Наступает время обновить чейнджлог. Вы выполняете строго 4 команды:bash

# 1. Генерируете новую порцию чейнджлога
git-cliff -o CHANGELOG.md

# 2. Добавляете обновленный файл в индекс
git add CHANGELOG.md

# 3. Делаете один технический релизный коммит
git commit -m "chore(release): prepare for v0.1.0-alpha.2"

# 4. Фиксируете версию тегом
git tag v0.1.0-alpha.2
